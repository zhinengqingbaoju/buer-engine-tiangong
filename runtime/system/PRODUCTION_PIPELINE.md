# 不二引擎十一阶段制作流程
版本：v01_20261007
性质：不二引擎重建版，不是HELL GRIND遗失官方11阶段。

01 项目简报与制作边界：目标/平台/时长/画幅/控制权/工具额度 → Project Brief。退出：目标、交付、授权清楚。主责：总控制片。
02 故事与剧本锁定：世界观/人物/剧情/场次/中文对白 → 有效剧本。退出：因果、动机、关键剧情与对白获批。主责：剧本叙事。
03 视觉系统与资产规划：剧本→人物/服装/场景/道具/状态/声音身份需求、缺口与复用表。主责：视觉资产。
04 资产制作、压力测试与锁定：真实资产、描述、状态版本、测试、候选/采用/锁定。锁定需用户确认。主责：视觉资产，QA参与。
05 场次空间与连续性设计：剧本+资产→GEO、地标、出入口、轴线、光线、continuity。主责：导演分镜。
06 分镜与镜头契约：Shotlist + Shot Contract；含职责、时长、首尾、人物数、机位、景别、动作、对白、声音、风险、参考。主责：导演分镜。
07 提示词编译与模型适配：合同+资产+GEO+对白→Master Prompt、目标模型Prompt、reference map、settings、unsupported。主责：生成工程。
08 生成前审计与提交准备：检查版本/参考/数量/模式/首尾/时长/对白/参数/授权/stale引用 → Ready-to-submit。主责：生成工程。
09 正式生成与生成记录：记录prompt/model/references/parameters/send/provider/result/reroll/cost证据。主责：生成工程；剪辑可并行试剪。
10 质检、返修、选片与锁镜：Expected vs Observed；reroll/rewrite/asset/geography/redesign/post；修后回QA；用户确认adopted/locked。主责：QA协调。
11 剪辑、后期、最终质检、交付与归档：粗剪/精剪/声画/SFX/音乐/字幕/调色/VFX/导出/整片检查/归档。用户终审。

跨阶段：PROJECT_STATE贯穿；Test属于生成工程模式；QA贯穿04/08/10/11；Repair是责任路由机制，不独立窗口。
