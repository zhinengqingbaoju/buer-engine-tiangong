# 天工核心数据模型
版本：v01_20261008

Project:
project_id,name,current_focus_object,current_stage,current_episode,current_scene,current_shot,active_versions,unresolved_decisions,blocked_items,next_action,updated_at
说明：current_stage 表示“当前焦点对象”的11阶段位置，不宣称整个项目只能处于一个阶段。

Decision:
decision_id,category,content,status(proposed/discussed/approved/superseded),approved_by,approved_at,replaces_decision_id,impact_scope,source

Script:
script_id,version,status(draft/review/approved/superseded),scene_ids,locked_dialogue_refs,source_decisions,approved_by,approved_at,replaces_script_version

Asset:
asset_id,name,category,base_identity_id,state_version,canonical_descriptor,actual_media_refs,reference_roles,do_not_inherit,source_decisions,status(planned/candidate/testing/adopted/locked/deprecated),test_scope,passed_conditions,untested_conditions,known_defects,drive_urls

Scene:
scene_id,script_id,script_version,location_asset_version,character_states,prop_states,GEO_version,continuity_in,continuity_out,scene_status,open_issues

GEO:
geo_id,scene_id,version,landmarks,entrances,exits,spatial_relations,screen_directions,axis_180,allowed_camera_sides,main_light_direction,restricted_zones,notes

Shot:
shot_id,scene_id,narrative_function,contract_version,duration_target,opening_state,closing_state,active_characters,asset_versions,geo_version,camera_contract,action_beats,dialogue_verbatim,audio_requirements,continuity_in,continuity_out,reference_needs,risk_focus,status

Prompt:
prompt_id,object_id,version,target_model,adapter_version,parent_prompt_version,actual_text,reference_mapping,platform_settings,changed_variables,change_reason,source_versions,unsupported_requirements,assumptions,status

Generation:
generation_id,object_id,prompt_id,prompt_version,model,model_version,adapter_version,actual_references,actual_parameters,send_status,provider_status,result_file,drive_url,reroll_index,cost_or_credits,cost_evidence,qa_status,selection_status

Issue:
issue_id,object_id,generation_id,category,severity,expected,observed,evidence_location,responsibility_layer,root_cause_status,recommended_route,status,resolved_by_version

Repair:
repair_id,issue_id,route,changed_variables,preserve_requirements,source_version,new_version,expected_improvement,retest_result,regression_result,decision

Selection:
selection_id,object_id,generation_id,status(candidate/rejected/adopted/locked/replaced),user_confirmation,known_defects,downstream_usage,replaces_selection_id

Task:
task_id,project_id,target_object,stage,target_role,goal,required_inputs,preserve_requirements,permissions,status(queued/ready/in_progress/waiting_user/waiting_authorization/blocked/done),blocked_reason,result_refs

Edit:
edit_id,edit_version,timeline,tracks,shot_generation_map,in_out,audio_usage,markers,transitions,cleanup_status,color_status,subtitle_status,open_gaps,final_export,review_status

Source:
source_id,category,authority_level,title,version_date,hash_url,current_status,applicable_modules,notes

RouteChange:
change_id,problem_found,old_route,new_route,reason,evidence,impact_scope,rollback,result

关系：
Decision→Script/Asset/Shot；
Script→Scene；
Scene→Asset/GEO；
Shot→Scene/GEO/Asset/Decision；
Prompt只引用批准事实；
Generation绑定Prompt；
Issue绑定Generation/对象；
Repair绑定Issue；
Selection绑定Generation；
Edit绑定Selection/Generation。
上游版本改变时，下游当前生产资格标 STALE / NEEDS_REVIEW，历史记录保留。
